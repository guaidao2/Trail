## 应急响应 playbook

### 阶段

1. **确认与取证（只读）**
   - 主机：`host_inspect`（processes/ports/users/cron/suid/logins）
   - 日志：`log_anomaly` 或 `host_download` 取 auth.log / access.log 片段
   - 保留证据：文件路径 + 哈希 + 时间戳；不要先删再查
2. **判断**
   - 把证据按时间线排列，区分"已确认事实"与"待验证线索"
   - 判断影响面：数据、可用性、是否横向
3. **止损（写操作，需审批）**
   - 常见动作：隔离网络、封禁 IP、停用账户、杀进程、关服务
   - 每个动作先写影响面与回滚方式；优先选择影响面小的手段
4. **复盘**
   - 输出：时间线、根因、影响范围、加固项（配置/补丁/监控）

### 常见误区

- 先重启再取证 → 内存与临时文件证据丢失
- 只清理不溯源 → 留后门与持久化项未清
- 结论写"疑似被入侵"却不给证据 → 无法复核
