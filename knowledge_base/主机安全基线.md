# 主机安全基线

## 账户与权限

- UID 0 仅 root；新增 UID 0 账户视为高危。
- 服务账户 shell 为 nologin/false；禁用无密码账户。
- sudo 权限最小化，定期核对 sudoers。

## SSH

- 禁用 root 直接登录与密码登录（改密钥）。
- 限制来源网段；开启失败登录告警。
- 变更前验证新通道可用，避免自锁。

## 持久化入口

- crontab / cron.d / systemd timer / rc.local / profile.d 纳入变更管理。
- 出现 curl|bash、base64 解码执行、随机命名脚本 → 高度可疑。

## 补丁与内核

- 安全补丁按月度窗口执行，先测试后生产。
- 关注内核提权漏洞公告，及时评估暴露面。

## 日志与监控

- auth.log / secure 保留 ≥ 90 天并集中收集。
- 监控关键文件哈希（/etc/passwd、sshd_config、站点目录）。
