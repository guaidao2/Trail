# 应急响应流程（简版）

## 0. 接警与范围

确认影响主机、业务、时间窗；确认授权范围。

## 1. 取证（只读）

- host_inspect：进程、端口、账户、计划任务、SUID、登录
- 日志片段、文件哈希、进程可执行文件路径
- 保留现场，不先删除/重启

## 2. 判断

时间线 + 影响面 + 是否横向；区分事实与线索。

## 3. 止损（需审批）

隔离网络 / 封禁 IP / 停用账户 / 杀进程 / 关服务；每步写影响面与回滚。

## 4. 根除与恢复

清理持久化项、修复入口（漏洞/弱口令）、恢复业务并观察。

## 5. 复盘

时间线、根因、影响范围、加固与监控改进项。
