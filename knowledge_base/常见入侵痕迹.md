# 常见入侵痕迹速查

## 进程

- 从 /tmp、/dev/shm、/var/tmp 启动的可执行文件
- 名称伪装（kworker/sshd）但路径不符
- 高 CPU 常驻（挖矿）、父进程已退出的孤儿进程

## 网络

- 对外监听的高位端口、无业务解释的长连接
- 与已知恶意 IP/域名通信（结合情报富化）
- 数据库/缓存端口绑定 0.0.0.0

## 账户

- 新增账户、UID 0 账户、最近修改密码的账户
- 异常时间/来源的成功登录；失败登录爆发

## 文件

- Web 目录下近期新增的脚本、内容含 eval/system/base64_decode
- 系统目录出现随机命名文件、SUID 位异常
- 配置文件中出现外联命令

## 持久化

- crontab 外联下载执行、systemd 自定义单元、rc.local 改动
- SSH authorized_keys 出现陌生公钥
