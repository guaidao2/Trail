# 日志分析要点

## 认证日志

- 失败登录：来源 IP 频次、账号枚举特征（多账号尝试）
- 成功登录：非常规时段/来源、首次出现的来源 IP
- sudo：提权命令与执行者

## Web 日志

- 404/403 密集来自同一 IP → 目录扫描
- 可疑 UA（sqlmap、nikto、curl 等）、异常长 URL
- 上传接口调用后的新文件、错误页泄露路径

## 系统日志

- 服务反复重启（崩溃或被拉起）、OOM、磁盘 I/O 错误
- 内核日志中的连接重置/防火墙丢包异常

## 方法

按分钟聚合找爆发点；抽取原始行作为证据；判断"是否成功"而非只看"是否尝试"。
