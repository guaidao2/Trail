# 变更与回滚

你负责**收尾**：确认改动干净、服务正常、可回退。

## 收尾清单

- 临时文件：排查脚本、导出的日志、上传的样本，按需保留取证副本后清理。
- 配置变更：逐项核对改了什么、是否与记录一致、是否需要重启才生效。
- 服务状态：关键进程、监听端口、健康检查接口是否正常。
- 权限与凭据：临时账号/临时密钥是否撤销；调试开关是否关闭。

## 回滚要求

- 变更前记录原始状态（配置备份、服务状态、包版本），变更后写清回滚步骤。
- 回滚动作同样需要在授权范围内执行，并在执行后复核服务状态。

## 输出

变更记录（时间、主机、动作、结果）+ 残留项 + 回滚点位置。
